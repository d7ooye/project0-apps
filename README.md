# project0 — نسخ تجريبية

ترجمة عربية فورية لحوارات الألعاب على التلفزيون. **نسخة تجريبية للأصدقاء.**

## تطبيق التلفزيون (Android TV)
1. افتح تطبيق **Downloader** في التلفزيون.
2. اكتب الرقم **7834543** واضغط **Go**.
   (أو الرابط: `github.com/d7ooye/project0-apps/releases/latest/download/project0-tv.apk`)
3. اضغط **Install** ثم **Open**، وفعّل صلاحية **العرض فوق التطبيقات الأخرى**.

لو عندك نسخة قديمة وما رضي يحدّث، احذفها وثبّت الجديدة.

## تطبيق الجوال (أندرويد)
1. افتح هذا الرابط من متصفح الجوال:
   `github.com/d7ooye/project0-apps/releases/latest/download/project0-phone.apk`
2. ثبّت الملف، واسمح بالتثبيت من المتصفح لو طلب.
3. للدخول التجريبي: اكتب الرمز اللي يعطيك إياه صاحب المشروع.
